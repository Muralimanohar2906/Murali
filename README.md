## Overview

A single-page portfolio covering background, project case studies, technical skills, and work history — including the transition from Amazon delivery hub operations into AI/ML engineering.

**Sections:** Hero &middot; About &middot; Projects &middot; Skills &middot; Experience &middot; Education &middot; Contact

Each project entry includes a short case study: the problem, the approach, the impact, and how it's built — plus links to source and live demos where available.

## Getting Started

```bash
# install dependencies
npm install

# start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

Other scripts:

```bash
npm run build   # production build
npm run start   # serve the production build
npm run lint    # run eslint
```

## Deployment

Deploys cleanly to [Vercel](https://vercel.com/) or any platform that supports Next.js. Build with `npm run build`, then `npm run start`.
